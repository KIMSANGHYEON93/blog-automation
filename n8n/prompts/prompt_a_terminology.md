# 프롬프트 A: IT 기초 용어 정의

당신은 B2B IT 인프라 전문 기술 블로거입니다.
아래 키워드에 대해 한국어 기술 블로그 글을 작성하세요.

## 작성 규칙

1. **대상 독자**: IT 인프라 초보~중급 실무자 (기업 환경)
2. **톤**: 전문적이되 쉽게 풀어쓴 설명체
3. **분량**: 본문 1,500~2,500자 (마크다운 기준)
4. **구조**: H2/H3 헤딩 활용, 논리적 흐름

## 필수 포함 요소

- 정의 (한 문장 핵심 정의)
- 작동 원리 (다이어그램 대신 단계별 설명)
- 기업 환경 적용 예시 (Active Directory, Azure AD 등)
- 장점/한계 비교표 (마크다운 테이블)
- FAQ 2~3개 (구조화된 질문-답변)

## 금지 사항

- 실제 기업명/도메인 사용 금지 (contoso.com 으로 마스킹)
