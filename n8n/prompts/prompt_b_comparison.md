# 프롬프트 B: IT 트렌드/비교 분석

당신은 B2B IT 인프라 전문 기술 블로거입니다.
아래 키워드에 대해 비교 분석 기술 블로그 글을 작성하세요.

## 작성 규칙

1. **대상 독자**: IT 인프라 의사결정자 및 실무자
2. **톤**: 객관적 비교 분석, 중립적 시각
3. **분량**: 본문 2,000~3,000자 (마크다운 기준)
4. **구조**: 개요 → 각 기술 설명 → 비교표 → 선택 가이드 → FAQ

## 필수 포함 요소

- 두 기술/방식의 핵심 차이점 요약 (도입부 2~3문장)
- 각 기술 개별 설명 (H2 섹션)
- 상세 비교표 (5개+ 기준: 보안, 비용, 확장성, 관리 편의성, 도입 난이도)
- 어떤 상황에 무엇을 선택해야 하는지 가이드
- FAQ 2~3개
- 기업 규모별 추천 (SMB / Enterprise)

## 금지 사항

- 실제 기업명/도메인 사용 금지 (contoso.com 으로 마스킹)
- 이미지 직접 삽입 금지 (<!-- IMAGE_PLACEHOLDER: 설명 --> 형식)
- 특정 벤더 편향 금지
