## 2. 키워드 캘린더 (메인 시트)

전체 34개 컬럼 (A~AH), 크게 5개 영역으로 구분됩니다.

### 기획 메타데이터 (A~I열)

| 열 | 컬럼명 | 작성 주체 | 설명 |
|----|--------|----------|------|
| A | No. | 자동/수동 | 일련번호 |
| B | 키워드 | **수동** | 검색 키워드 (필수) |
| C | 카테고리 | Pipeline A / 수동 | 용어, 비교, 에러, 가이드, 트렌드 |
| D | 콘텐츠유형 | Pipeline A / 수동 | 용어 정의, 비교/분석, How-to 가이드, 에러 해결 |
| E | 검색볼륨 | Pipeline A / SERP | 월간 검색량 |
| F | 예상CPC | Pipeline A / SERP | 클릭당 비용 (원) |
| G | 난이도 | SERP 분석 | 상/중/하 (경쟁도 기반) |
| H | 우선순위 | 자동 계산 | S/A/B (볼륨 x CPC / 난이도) |
| I | 예정일 | 수동/자동 | YYYY-MM-DD 발행 예정일 |

> **B열(키워드)과 J열(상태=대기)만 입력하면** 다음 Pipeline A 실행 시 자동으로 콘텐츠가 생성됩니다.

### 상태 (J열)

| 열 | 컬럼명 | 작성 주체 | 설명 |
|----|--------|----------|------|
| J | 상태 | Pipeline A/B | 현재 처리 단계 ([상태값 흐름](#7-상태값-흐름) 참고) |

### 생성 데이터 (K~P열)

Pipeline A가 LLM으로 생성한 콘텐츠입니다. **수동 수정하지 마세요.**

| 열 | 컬럼명 | 작성 주체 | 설명 |
|----|--------|----------|------|
| K | 제목 | Pipeline A | 블로그 글 제목 |
| L | 메타설명 | Pipeline A | SEO 메타 디스크립션 (160자 이내) |
| M | 태그 | Pipeline A | 쉼표 구분 태그 목록 |
| N | FAQ스키마 | Pipeline A | JSON-LD FAQ 스키마 (리치 스니펫용) |
| O | 참고자료 | Pipeline A | SERP 기반 참고 URL 목록 |
| P | 본문마크다운 | Pipeline A | 전체 콘텐츠 (마크다운 형식) |

### 발행/운영 데이터 (Q~Y열)

Pipeline B가 발행 과정에서 기록합니다.

| 열 | 컬럼명 | 작성 주체 | 설명 |
|----|--------|----------|------|
| Q | 발행URL | Pipeline B | 발행된 글의 URL |
| R | 발행일시 | Pipeline B | YYYY-MM-DD HH:MM:SS |
| S | 색인여부 | Pipeline B / 스크립트 | O (색인됨) / X (미색인) |
| T | 에러메시지 | Pipeline B | 발행 실패 시 오류 내용 |
| U | SERP데이터 | 스크립트 | SerpAPI 분석 결과 JSON |
| V | 프롬프트유형 | Pipeline A | A(용어)/B(비교)/C(에러해결) |
| W | Haiku검증 | Pipeline A | 교차 검증 결과 (PASS/FAIL + 점수) |
| X | 내부링크키워드 | Pipeline A | 관련 키워드 JSON (내부 링크 삽입용) |
| Y | 비고 | 수동 | 메모 |

### 확장 운영 컬럼 (Z~AH열)

자동 추적용 확장 컬럼입니다.

| 열 | 컬럼명 | 작성 주체 | 설명 |
|----|--------|----------|------|
| Z | 생성일시 | Pipeline A | 콘텐츠 최초 생성 시각 |
| AA | 썸네일URL | Pipeline B | 대표 이미지 URL |
| AB | 엔트리ID | Pipeline B | 티스토리 게시글 고유 ID |
| AC | 수정횟수 | Pipeline B | 수정 발행 누적 횟수 |
| AD | CWV_LCP | Pipeline B | Core Web Vitals LCP (초) |
| AE | CWV_CLS | Pipeline B | Core Web Vitals CLS |
| AF | CWV점검일시 | Pipeline B | CWV 점검 시각 |
| AG | 최종수정일시 | Pipeline B | 마지막 수정 발행 시각 |
| AH | 수정사유 | Pipeline B | 수정 이유 (미색인, 품질개선 등) |

## 3. 성과 대시보드

`update_dashboard.py` 스크립트가 자동으로 갱신하는 주간 KPI 탭입니다.

### 구조

```
Row 1 : (빈 행)
Row 2 : 그룹 헤더  — 기본 | Pipeline A | Pipeline B | SEO 성과 | 수동입력
Row 3 : KPI 헤더   — 주차, 기간, PL-A성공률, ...
Row 4~ : 주간 데이터
Row 15: 목표행     — 각 KPI 목표 기준값
Row 17~21: 요약 섹션
```

### 컬럼 구성

| 그룹 | 열 | 항목 | 데이터 소스 |
|------|-----|------|-----------|
| **기본** | A | 주차 | 자동 계산 (W01, W02, ...) |
| | B | 기간 | 자동 계산 (03/03~03/09) |
| **Pipeline A** | C | PL-A 성공률 | 생성 성공 / 전체 대기 |
| | D | 검증통과율 | Haiku 검증 PASS 비율 |
| **Pipeline B** | E | 신규발행 | 해당 주 발행 건수 |
| | F | 누적발행 | 전체 발행완료 누적 |
| | G | PL-B 성공률 | 발행 성공 / 시도 |
| **SEO 성과** | H | 색인수 | 색인된 글 수 |
| | I | 총노출 | GSC 노출 수 |
| | J | 총클릭 | GSC 클릭 수 |
| | K | 평균CTR | GSC 평균 클릭률 |
| | L | 일평균유입 | GSC 일 평균 클릭 |
| | M | 평균순위 | GSC 평균 검색 순위 |
| **수동입력** | N | 애드센스수익 | 수동 입력 |
| | O | 비고 | 수동 메모 |

### 요약 섹션 (Row 17~21)

| 행 | 항목 | 계산 방법 |
|----|------|----------|
| 17 | 총 발행수 | 발행완료 + 수정대기 총합 |
| 18 | 누적 색인률 | 색인수 / 발행수 x 100% |
| 19 | 전체 평균CTR | 전체 클릭 / 전체 노출 |
| 20 | 최근 일평균유입 | 최근 주차 일평균유입 |
| 21 | 반려율 | 발행실패 / (발행완료+실패) |

### 업데이트 방법

```bash
python scripts/update_dashboard.py           # 실행
python scripts/update_dashboard.py --dry-run  # 미리보기
```

## 4. 키워드 피라미드

SEO 허브-스포크 전략을 위한 내부 링크 설계 맵입니다.

### 컬럼 구조

| 열 | 컬럼명 | 설명 |
|----|--------|------|
| A | 계층 | Top(허브) / Mid(중간) / Bottom(하위) |
| B | 키워드 | 해당 키워드 |
| C | 카테고리 | 소속 카테고리 |
| D | 검색볼륨 | 월간 검색량 |
| E | 연결 키워드 | 내부 링크로 연결된 관련 키워드 |
| F | 발행URL | 발행된 글 URL |

### 계층 분류 기준

| 계층 | 검색볼륨 | 역할 |
|------|---------|------|
| **Top** (허브) | 2,000 이상 | 트래픽 앵커, 여러 하위 글에서 링크 |
| **Mid** (중간) | 500 ~ 1,999 | 허브와 롱테일 연결 |
| **Bottom** (하위) | 500 미만 | 고CPC 롱테일, 상위 허브로 링크 |

## 7. 상태값 흐름

J열(상태)에 사용되는 값과 전이 규칙:

```
대기 ──→ 발행대기 ──→ 발행중 ──→ 발행완료
 │         ↑           │
 │         │           ↓
 │         │       발행실패
 │         │         │ ↑
 │         └─────────┘ │
 │       (자동 복구)    │
 │                     ↓
 │                 수정대기 ──→ 수정중 ──→ 발행완료
 │                               ↓
 └─ (Pipeline A)              발행실패
```

| 상태 | 의미 | 다음 단계 |
|------|------|----------|
| **대기** | 키워드만 입력, 콘텐츠 미생성 | Pipeline A가 콘텐츠 생성 → 발행대기 |
| **발행대기** | 콘텐츠 생성 완료, 발행 대기 중 | Pipeline B가 발행 시도 → 발행중 |
| **발행중** | 현재 발행 진행 중 | 성공 → 발행완료 / 실패 → 발행실패 |
| **발행완료** | 정상 발행됨 | 수정 필요 시 → 수정대기 |
| **발행실패** | 발행 중 오류 발생 | 자동 복구 → 발행대기 / 수동 확인 필요 |
| **수정대기** | 기존 글 수정이 필요한 상태 | `--revise` 실행 → 수정중 |
| **수정중** | 수정 발행 진행 중 | 성공 → 발행완료 / 실패 → 발행실패 |

## 8. 운영 워크플로우

### 새 키워드 추가

1. 키워드 캘린더 시트에 새 행 추가
2. **B열**(키워드) 입력
3. **J열**(상태) = `대기` 입력
4. (선택) C열(카테고리) 입력 — 미입력 시 자동 분류
5. Pipeline A가 다음 실행 시 자동으로 콘텐츠 생성

### 발행 실패 처리

1. T열(에러메시지) 확인
2. `python -m src.interface.cli --recover-failed` 실행
3. 자동 복구 가능한 건은 발행대기로 전환
4. 수동 확인 필요한 건은 T열 메시지를 참고하여 수정

### 미색인 글 재처리

1. `python -m src.interface.cli --check-index` 실행
2. 미색인 글은 자동으로 수정대기 전환
3. `python -m src.interface.cli --revise` 실행하여 재발행

### 대시보드 갱신

```bash
# 주간 KPI + 피라미드 + 로그 일괄 업데이트
python scripts/update_dashboard.py
```

수동 입력 항목 (애드센스 수익, 비고)은 시트에서 직접 입력합니다.

### 수동 수정 시 주의사항

- **J열(상태)**: Pipeline A/B가 관리하므로 임의 변경 시 오류 발생 가능
- **K~P열(생성 데이터)**: Pipeline A가 덮어쓸 수 있으므로 수정 시 상태를 `발행대기`로 유지
- **Q열(발행URL)**: 수동 삭제 시 중복 발행 위험
- **AB열(엔트리ID)**: 수정 발행에 필수이므로 삭제 금지
